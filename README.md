# UniFlow – Freshmen Adaptation Mobile App

## 📌 Overview

**UniFlow** is a mobile application prototype designed to improve the adaptation experience of freshmen students in universities. The project focuses on helping new students easily navigate academic, social, and campus-related challenges through a centralized and user-friendly platform.

The application was designed and prototyped using **Figma** with a strong emphasis on intuitive UI/UX principles and user-centered problem solving.

---

# ✨ Features

## 📢 Event Notifications
- Provides updates about university events, workshops, seminars, and student activities.
- Helps freshmen stay informed and engaged with campus life.

## 🎥 Recorded Lectures
- Centralized access to recorded lectures for revision and self-paced learning.
- Assists students who miss classes or need additional review.

## 🚌 Shuttle Timings
- Displays real-time or scheduled campus shuttle timings.
- Simplifies transportation management for students.

## 🗺️ Campus Navigation
- Interactive campus map to help students locate classrooms, labs, libraries, cafeterias, and administrative offices.
- Reduces confusion for new students navigating campus.

## 👥 Social Interaction
- Enables students to connect with peers and build communities.
- Encourages collaboration and improves student engagement.

## 📚 Library Access
- Provides library-related services such as book availability and issue tracking.
- Improves accessibility to academic resources.

## ⭐ Lecturer Feedback System
- Allows students to submit feedback regarding lecturers and courses.
- Encourages communication and academic improvement.

## 👤 Student Profile Management
- Personalized student profiles containing academic and activity-related information.
- Enables easy access to student-specific resources.
